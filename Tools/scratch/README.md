# Scratch

One-off investigation scripts and images, kept for the record. Nothing here is part of the toolchain: these were
written to answer a single question (where a vertex sits, what a decal mask looks like, which bundle holds a map) and
were never meant to be maintained. If one of them turns out to matter, move it up into `Tools/` and document it in
`Tools/README.md`.

|name|what it was|
|`probe_*.py`|one-question probes into the game data, the shaders and the exported files|
|`_*.py`, `_*.png`|ad-hoc helpers and screenshots taken to compare one render against another|
|`Program.cs`|an empty file a tool left behind|
|`Config.json.bak_*`|a saved `Config.json` from a working copy|
|`property_metadata_dirty_check.json`|a temporary report|
